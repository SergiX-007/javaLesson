01Le squelette d'un programme

En Java, tout vit dans une classe, et le programme démarre toujours par une méthode spéciale appelée main. Voici le minimum qui tourne :

public class Programme {
    public static void main(String[] args) {
        System.out.println("Bonjour !");
    }
}
Règle qui fait rater 50 % des débutants Le fichier doit s'appeler exactement comme la classe public + .java. Ici : la classe est Programme → le fichier doit être Programme.java. Sinon ça ne compile pas.

À retenir mot à mot (tu le réécriras à chaque fois) :

  • public class Nom → tu déclares ta classe.
  • public static void main(String[] args) → le point d'entrée, là où l'exécution commence.
  • Chaque instruction se termine par un ; (point-virgule).
  • Les blocs sont délimités par des { }.

02Afficher à l'écran

System.out.println("Ligne 1"); // va à la ligne
System.out.print("a");      // reste sur la ligne
System.out.print("b");
System.out.println();       // ligne vide
SortieLigne 1

Pour coller du texte et des valeurs, on utilise le + (concaténation) :

int age = 25;
System.out.println("Tu as " + age + " ans");  // Tu as 25 ans
Différence à connaître println = « print line » → affiche et saute une ligne. print → affiche sans sauter. C'est tout.

03Variables & types

Une variable = une boîte étiquetée qui garde une valeur. En Java tu annonces le type de la boîte :

int nombre   = 10;          // entier
double prix  = 9.99;        // décimal (virgule flottante)
boolean ok   = true;        // vrai / faux
char lettre  = 'A';         // UN caractère (guillemets simples)
String nom   = "Sergio";    // texte (guillemets doubles)

04Saisie au clavier (Scanner)

Pour lire ce que l'utilisateur tape, Java utilise l'objet Scanner. Trois étapes :

import java.util.Scanner;   // 1) tout en haut du fichier

public class Saisie {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);  // 2) on crée le lecteur

        System.out.print("Ton prénom : ");
        String prenom = sc.nextLine();          // 3) on lit du texte

        System.out.print("Ton âge : ");
        int age = sc.nextInt();               // on lit un entier

        System.out.println("Salut " + prenom + ", " + age + " ans !");

        sc.close();   // on ferme à la fin
    }
}
MéthodeLit…
sc.nextLine()une ligne de texte (String)
sc.nextInt()un entier (int)
sc.nextDouble()un décimal (double)
sc.next()un seul mot (sans espace)
LE piège d'examen à connaître absolument Si tu fais nextInt() puis nextLine(), le second te renvoie une ligne vide : nextInt() laisse le « retour-chariot » derrière lui. La parade simple : ajoute un sc.nextLine(); « poubelle » juste après le nextInt() pour l'avaler, ou lis tout avec nextLine() puis convertis avec Integer.parseInt(...).

06Les boucles (répéter)

Boucle for — quand tu sais combien de fois

// affiche 1, 2, 3, 4, 5
for (int i = 1; i <= 5; i++) {
    System.out.println("Tour n° " + i);
}

Les 3 parties du for : départ (int i = 1) ; condition pour continuer (i <= 5) ; pas à chaque tour (i++, càd « i = i + 1 »).

Boucle while — tant qu'une condition est vraie

int compteur = 0;
while (compteur < 3) {
    System.out.println("encore");
    compteur++;          // SANS ça → boucle infinie !
}

Boucle do…while — s'exécute au moins une fois

Scanner sc = new Scanner(System.in);
int n;
do {
    System.out.print("Entre un nombre positif : ");
    n = sc.nextInt();
} while (n <= 0);   // redemande tant que ≤ 0
Comment choisir Nombre de tours connu (de 1 à 10, parcourir un tableau) → for. Répéter tant qu'une condition tient (jusqu'à une bonne saisie) → while / do…while.

07Les fonctions (méthodes)

En Java, une « fonction » s'appelle une méthode. C'est un bloc de code nommé qu'on peut appeler autant de fois qu'on veut — ça évite de recopier le même code partout.

L'anatomie d'une méthode

static int addition(int a, int b) {
    return a + b;   // renvoie le résultat
}
  • static → permet de l'appeler directement depuis main (voir l'avertissement plus bas).
  • int → le type de la valeur renvoyée par return.
  • addition → le nom que tu choisis.
  • (int a, int b) → les paramètres : les valeurs qu'on lui donne en entrée.
  • return → renvoie le résultat et arrête la méthode.

Une méthode qui ne renvoie rien : void

static void saluer(String nom) {
    System.out.println("Bonjour " + nom + " !");
}

void = « ne renvoie rien ». La méthode fait juste une action (ici, afficher).

Les appeler depuis main

public class Demo {
    public static void main(String[] args) {
        saluer("Sergio");              // affiche : Bonjour Sergio !
        int r = addition(3, 5);        // r vaut 8
        System.out.println("3 + 5 = " + r);
    }

    static void saluer(String nom) {
        System.out.println("Bonjour " + nom + " !");
    }

    static int addition(int a, int b) {
        return a + b;
    }
}
SortieBonjour Sergio !
3 + 5 = 8
Paramètre vs argument Le paramètre = la variable dans la définition (int a). L'argument = la valeur réelle passée à l'appel (3). On dit « la méthode reçoit des arguments ».
Le mot-clé static (erreur ultra fréquente) Comme main est static, les méthodes qu'elle appelle dans la même classe doivent l'être aussi. Sinon : non-static method ... cannot be referenced from a static context. En résumé : dans un petit programme, mets static sur toutes tes méthodes utilitaires.
Lien avec les objets Les méthodes d'un objet (comme sePresenter() au §8) sont aussi des fonctions — mais sans static, car elles agissent sur un objet précis (e1.sePresenter()).

08Les objets (classes = « structures »)

En Java, une « structure » qui regroupe plusieurs données, ça s'appelle une classe. Une classe décrit :

  • des attributs (les données : nom, âge…) ;
  • un constructeur (la recette pour fabriquer un objet) ;
  • des méthodes (ce que l'objet sait faire).

Exemple : une classe Etudiant.

class Etudiant {
    // --- attributs (la "structure") ---
    String nom;
    int age;

    // --- constructeur : sert à créer un Etudiant ---
    Etudiant(String nom, int age) {
        this.nom = nom;    // "this.nom" = l'attribut de l'objet
        this.age = age;
    }

    // --- une méthode : un comportement ---
    void sePresenter() {
        System.out.println("Je suis " + nom + ", " + age + " ans.");
    }
}

On crée et utilise des objets avec new et le point . :

Etudiant e1 = new Etudiant("Sergio", 25);
Etudiant e2 = new Etudiant("Léa", 22);

e1.sePresenter();          // Je suis Sergio, 25 ans.
System.out.println(e2.nom);  // accès direct à un attribut → Léa
L'image mentale La classe = le plan / le moule (« un Etudiant a un nom et un âge »). L'objet = un exemplaire fabriqué avec ce moule (« Sergio, 25 ans »). new = « fabrique-m'en un ». Java n'a pas de struct comme en C : ici, la classe joue ce rôle.

09Le programme complet (tout ensemble)

Ce programme combine tes 4 notions : il demande combien d'étudiants saisir, lit chacun au clavier (saisie), les range dans un tableau d'objets (objets), les affiche avec une boucle (boucle + affichage), et calcule l'âge moyen. Copie-le tel quel dans un fichier Ecole.java.

import java.util.Scanner;

// ---- la "structure" étudiant ----
class Etudiant {
    String nom;
    int age;
    Etudiant(String nom, int age) {
        this.nom = nom;
        this.age = age;
    }
    void afficher() {
        System.out.println(" - " + nom + " (" + age + " ans)");
    }
}

public class Ecole {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Combien d'étudiants ? ");
        int n = sc.nextInt();
        sc.nextLine();   // avale le retour-chariot (le piège du §4 !)

        Etudiant[] liste = new Etudiant[n];   // tableau d'objets

        // --- SAISIE : on remplit le tableau avec une boucle ---
        for (int i = 0; i < n; i++) {
            System.out.print("Nom de l'étudiant " + (i + 1) + " : ");
            String nom = sc.nextLine();

            System.out.print("Son âge : ");
            int age = sc.nextInt();
            sc.nextLine();

            liste[i] = new Etudiant(nom, age);   // on crée l'objet
        }

        // --- AFFICHAGE + calcul de la moyenne ---
        System.out.println("\n=== Liste des étudiants ===");
        int total = 0;
        for (int i = 0; i < n; i++) {
            liste[i].afficher();
            total = total + liste[i].age;
        }

        double moyenne = (double) total / n;
        System.out.println("Âge moyen : " + moyenne);

        sc.close();
    }
}
Exemple d'exécutionCombien d'étudiants ? 2
Nom de l'étudiant 1 : Sergio
Son âge : 25
Nom de l'étudiant 2 : Léa
Son âge : 22

 - Léa (22 ans)
Âge moyen : 23.5
Tu as tout Ce seul fichier utilise : Scanner (saisie), System.out.println (affichage), for (boucles) et une classe Etudiant (objets/structure). Adapte les noms d'attributs (nom → produit, age → prix…) et tu couvres la plupart des sujets d'exam.

10Lire & écrire dans un fichier

Un programme oublie tout quand il se ferme. Pour garder des données (ou relire un fichier existant), on écrit/lit sur le disque. Java manipule surtout du texte.

Écrire dans un fichier — FileWriter

import java.io.FileWriter;
import java.io.IOException;

public class Ecriture {
    public static void main(String[] args) throws IOException {

        FileWriter f = new FileWriter("donnees.txt");  // crée (ou écrase) le fichier
        f.write("Sergio;25\n");   // \n = saut de ligne
        f.write("Lea;22\n");
        f.close();                // OBLIGATOIRE, sinon le fichier peut rester vide

        System.out.println("Fichier écrit !");
    }
}

Lire un fichier — Scanner + File

import java.io.File;
import java.io.FileNotFoundException;
import java.util.Scanner;

public class Lecture {
    public static void main(String[] args) throws FileNotFoundException {

        Scanner lecteur = new Scanner(new File("donnees.txt"));

        while (lecteur.hasNextLine()) {      // tant qu'il reste une ligne
            String ligne = lecteur.nextLine();
            System.out.println("Lu : " + ligne);
        }
        lecteur.close();
    }
}
SortieLu : Sergio;25
Lu : Lea;22
Le throws IOException — pourquoi ? Un fichier peut échouer (introuvable, disque plein, pas les droits…). Java t'oblige à prévoir le coup. Le plus simple pour un exercice : ajouter throws IOException (ou throws FileNotFoundException) après main, comme ci-dessus. Alternative plus propre : entourer d'un try { … } catch (IOException e) { … }.
Écraser ou ajouter à la suite ? new FileWriter("donnees.txt") → efface et réécrit tout.
new FileWriter("donnees.txt", true) → ajoute à la fin (le true = mode « append »).
Où est créé le fichier ? Par défaut, dans le dossier d'où tu lances java. Tu peux donner un chemin complet : new FileWriter("/home/hsergio/donnees.txt").

En pratique : (re)lire des objets

On sauvegarde souvent une donnée par ligne, champs séparés par un ;. Pour les relire, on découpe la ligne avec split :

String ligne = "Sergio;25";
String[] parts = ligne.split(";");   // ["Sergio", "25"]
String nom = parts[0];
int age = Integer.parseInt(parts[1]);  // le texte "25" devient le nombre 25
Etudiant e = new Etudiant(nom, age);       // on recrée l'objet (voir §8)
Version courte (Java 11+) Plus moderne, tout tient en 2 lignes :
Files.writeString(Path.of("donnees.txt"), "du texte\n");
String tout = Files.readString(Path.of("donnees.txt"));
(avec import java.nio.file.Files; et import java.nio.file.Path;). Pour lire ligne par ligne, Files.readAllLines(...) renvoie une List<String>.

11Compiler & exécuter

Deux commandes dans le terminal, dans le dossier où est ton fichier :

# 1) compiler : transforme Ecole.java en Ecole.class
javac Ecole.java

# 2) exécuter : on lance SANS le .class, juste le nom de la classe
java Ecole
3 erreurs de compilation classiques • Le nom du fichier ≠ nom de la classe public → renomme.
• Un ; oublié en fin de ligne, ou une } manquante.
• À l'exécution tu tapes java Ecole, pas java Ecole.class ni java Ecole.java.
